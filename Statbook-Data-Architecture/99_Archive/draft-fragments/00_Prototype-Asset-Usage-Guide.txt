## Purpose

This document explains how visual assets should be used in the Bulldog Statbook static prototype.

It exists to help Codex and contributors use available assets consistently and avoid introducing off-brand placeholder graphics.

This guide applies only to the **static prototype phase**.

---

## Asset Use Principle

When real Bulldog brand assets are available, use them carefully and consistently.

When real assets are not available, use restrained text-based substitutes rather than invented graphics.

The prototype should feel:
- credible
- brand-aligned
- clean
- product-grade

The prototype should not include fake branding elements that weaken trust.

---

## Approved Asset Categories

The static prototype may use the following asset types:

### 1. Official Bulldog logo / wordmark assets
Examples:
- Bulldog wordmark
- Bulldog logo mark
- dark/light variants
- favicon

### 2. Brand reference screenshots
Examples:
- bulldogstats.com homepage screenshots
- navigation/header screenshots
- hero/brand section screenshots

These are for **reference only**, not for direct UI embedding unless intentionally approved.

### 3. Product-neutral UI assets
Examples:
- simple icons
- system-safe UI glyphs
- neutral status indicators

These should be used sparingly.

---

## Primary Rule for Logo Use

If official Bulldog logo or wordmark files are available:

- use the official assets
- preserve proportions
- do not stretch or distort them
- do not recolor them arbitrarily
- do not apply gimmick effects
- do not redraw the bulldog mark
- do not substitute clip-art or AI-generated mascot art

If official assets are **not** available:

- use a text-based treatment instead
- keep it minimal and brand-appropriate
- prefer:
  - **BULLDOG**
  - **Stats & Sports Innovation**
  - **Bulldog Statbook**

Do not invent a fake bulldog logo.

---

## Recommended Fallback Brand Treatment

When no official logo files are available, use a clean text-only brand treatment such as:

**BULLDOG**  
_Stats & Sports Innovation_

or

**Bulldog Statbook**  
_Stats & Sports Innovation_

This fallback should feel:
- bold
- structured
- restrained
- product-oriented

It should not try to mimic a mascot logo.

---

## Screenshot Usage Rules

Screenshots from bulldogstats.com are useful as **brand reference material**.

They should be used to guide:
- color palette
- typography tone
- spacing
- button character
- header composition
- overall visual confidence

They should **not** be:
- copied directly into the app UI as page backgrounds
- sliced into the prototype as decorative panels
- used as fake product screens
- repurposed in a way that makes the prototype feel like a collage

Reference screenshots are for design alignment, not for direct composition.

---

## Asset Placement Guidance

### Login / Entry Page (`index.html`)
Allowed:
- official wordmark/logo if available
- fallback text brand block if not
- subtle, restrained visual branding

Avoid:
- oversized decorative graphics
- marketing-site collage effects
- fake sports imagery
- clip-art

### Sidebar / App Shell
Allowed:
- small official wordmark or text brand treatment
- subtle favicon/mark if it exists and fits cleanly

Avoid:
- large promotional hero graphics
- visually noisy branded wallpaper
- repeated logo stamping

### Team / Identity / Guardian Pages
Allowed:
- little to no decorative asset usage
- focus on product UI, typography, color, and structure

Avoid:
- using graphics where layout clarity should do the work
- sports-themed decoration that reduces seriousness

---

## Icon Usage Guidance

If icons are used in the static prototype:

- keep them simple
- keep them consistent
- use line icons or minimal UI icons only
- ensure they support clarity rather than decoration

Good uses:
- navigation icons
- status/context icons
- utility actions

Avoid:
- cartoon sports icons
- mascot illustrations
- decorative icon overload
- highly stylized icon packs that clash with the Bulldog tone

---

## Color and Asset Relationship

Assets should support the Bulldog visual system, not compete with it.

The prototype should rely primarily on:
- typography
- layout
- spacing
- color
- hierarchy

—not on heavy graphic decoration.

Brand presence should come from:
- dark/navy framing
- Bulldog green actions
- confident headings
- restrained logo placement
- serious product composition

---

## Do Not Use

The following should not appear in the prototype unless explicitly approved:

- fake bulldog mascot illustrations
- AI-generated replacement logos
- generic sports clip-art
- hockey-specific imagery unless truly relevant
- loud action-photo collages
- unrelated stock photos
- decorative textures
- generic startup gradients
- neon highlights
- overly playful sticker-style graphics

---

## Acceptable Placeholder Strategy

If the prototype lacks real assets, the correct fallback is:

1. use text-based branding
2. use the Bulldog-inspired color palette
3. use strong typography and spacing
4. keep visuals restrained and product-focused

This is better than introducing low-quality placeholder graphics.

---

## Asset Storage Guidance

Place prototype assets in the following folders:

### Logos
`05_Prototype-Assets/logos/`

### Screenshots
`05_Prototype-Assets/screenshots/`

### Brand notes
`05_Prototype-Assets/brand/`

### Miscellaneous asset notes
`05_Prototype-Assets/notes/`

Suggested file naming:
- `bulldog-wordmark.svg`
- `bulldog-wordmark-dark.svg`
- `bulldog-wordmark-light.svg`
- `bulldog-logo-mark.svg`
- `bulldogstats-homepage-reference.png`
- `bulldogstats-nav-reference.png`

---

## Codex Guidance

When Codex is generating or refining the static prototype:

- use official Bulldog assets if they are present and clearly labeled
- if assets are missing, use text-only brand treatment
- never fabricate substitute mascot graphics
- treat screenshots as visual references, not content blocks
- prioritize product credibility over decorative branding

---

## Review Standard

Asset usage is correct if:

- the prototype feels clearly connected to Bulldog
- branding feels restrained and intentional
- no fake or awkward logo substitutes appear
- the UI feels product-grade rather than collage-based
- visual trust is maintained

Asset usage is incorrect if:

- the prototype includes invented logos
- screenshots are pasted into the UI as decoration
- clip-art or mascot graphics reduce credibility
- branding feels noisy or inconsistent

---

## Final Reminder

For Bulldog Statbook, strong branding in the prototype should come primarily from:

- visual restraint
- typography
- color system
- layout confidence
- clean use of real assets when available

Not from decorative filler.
