# Bulldog Statbook Static Prototype

This folder contains the current active static prototype for Bulldog Statbook.

Purpose:  
- desktop-first UX evaluation  
- visual review  
- brand alignment with bulldogstats.com

Deployment:  
- static HTML/CSS/JS  
- suitable for Cloudflare Pages

Primary files:  
- index.html  
- dashboard.html  
- teams.html  
- team-detail.html  
- create-team.html  
- player-identity.html  
- guardian-relationships.html  
- styles.css  
- app.js  

## Cloudflare Pages preview

Deploy this folder as a static site with no build command. Set `index.html` as the entry page and include the `assets/` directory with the HTML, CSS, and JavaScript files. The remaining pages are linked with relative paths, so no rewrites are required for the prototype review.
