## Purpose

This folder contains the current active static prototype for Bulldog Statbook.

The prototype exists to support:

- desktop-first UX evaluation  
- visual review  
- brand alignment with bulldogstats.com  
- stakeholder walkthroughs  
- future Laravel implementation planning

This is the active working prototype location.

---

## Current Scope

The prototype is intended to be a static front-end only implementation using:

- HTML  
- CSS  
- lightweight JavaScript

This prototype is not intended to be a full production build.

It should demonstrate:

- layout direction  
- interaction patterns  
- information hierarchy  
- visual brand alignment  
- product credibility

---

## Expected Files

The current prototype should include these files:

- `index.html`  
- `dashboard.html`  
- `teams.html`  
- `team-detail.html`  
- `create-team.html`  
- `player-identity.html`  
- `guardian-relationships.html`  
- `styles.css`  
- `app.js`

---

## Primary Experience Goal

The prototype should feel like a credible Bulldog software product rather than a generic admin template.

Key goals:

- desktop-first layout  
- clear app shell and navigation  
- serious, product-grade presentation  
- strong readability  
- restrained but visible Bulldog brand alignment

Most importantly:

## `team-detail.html` should be the strongest page

It should feel like the operational center of the product.

---

## Brand Direction

The prototype should visually align with bulldogstats.com through:

- dark/navy foundation  
- Bulldog green actions and accents  
- bold headings  
- confident spacing  
- restrained logo usage  
- clean product composition

Avoid:

- generic dashboard styling  
- fake mascot art  
- clip-art  
- noisy placeholder visuals  
- collage-style screenshot usage

---

## Deployment

This folder is intended to be deployable as a static site.

Suitable hosting targets include:

- Cloudflare Pages  
- GitHub Pages  
- Netlify  
- other static hosting options
