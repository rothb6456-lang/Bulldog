## Purpose

This file captures refinement ideas and implementation notes for improving the Bulldog Statbook static prototype over multiple iterations.

Unlike feedback notes, which capture observations, this file should focus more on concrete improvement direction.

---

## Refinement Goals

The prototype should gradually improve in these areas:

- brand alignment  
- visual hierarchy  
- desktop confidence  
- information architecture  
- usability of forms and tables  
- consistency across pages  
- clarity of action paths  
- perceived product quality

---

## Current Refinement Priorities

### 1. Strengthen team-detail page  
The `team-detail.html` page should feel like the operational center of the product.

Refinement focus:  
- clearer top summary section  
- better roster/action organization  
- stronger visual grouping  
- improved utility/action placement  
- more convincing product hierarchy

### 2. Reduce generic dashboard feel  
The prototype should not resemble a default SaaS admin template.

Refinement focus:  
- stronger Bulldog color use  
- more confident headings  
- less template-like card repetition  
- more purposeful spacing and grouping

### 3. Improve desktop layout rhythm  
The UI should feel intentionally designed for desktop.

Refinement focus:  
- stronger use of columns  
- better panel balance  
- improved table width usage  
- less narrow or cramped page composition

### 4. Improve consistency  
Pages should feel like parts of one product system.

Refinement focus:  
- repeated layout patterns  
- consistent card, table, and form styles  
- consistent button hierarchy  
- consistent spacing scale

## Visual Refinement Notes

### Color  
- use Bulldog green strategically for emphasis and action  
- keep dark/navy framing stable  
- avoid too many accent colors

### Typography  
- headings should feel stronger  
- secondary labels should remain readable  
- hierarchy should be immediately visible

### Spacing  
- increase consistency  
- avoid random gaps  
- keep dense areas readable

### Components  
- tables should feel usable and professional  
- forms should feel intentional, not default  
- cards should support hierarchy, not create clutter

---

## Refinement Questions

Use these questions while improving the prototype:

- What still feels generic?  
- What still feels unfinished?  
- Which page needs the most visual confidence?  
- Is the hierarchy obvious within five seconds?  
- Does the UI look like it belongs to Bulldog?  
- Which elements are decorative rather than useful?  
- What would make this easier to build later in Laravel?
