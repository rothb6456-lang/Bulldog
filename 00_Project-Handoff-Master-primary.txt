## Purpose

This document is a single-file handoff summary intended to bring a new chat, assistant, or contributor up to speed quickly on the current state of the Bulldog Statbook project.

It summarizes what has been created since the earlier planning phase and especially since the point referred to as **“Group 6 preliminary lock candidates.”**

This file should be used as the fastest orientation document before diving into the more specific source files.

---

## Executive Summary

The Bulldog Statbook project has progressed from early data architecture and Laravel planning into a much more structured **static prototype phase**.

A dedicated repository structure has now been organized with:

1. top-level governance files    
2. product/planning documents    
3. Laravel architecture documents    
4. Codex build-guidance documents    
5. deployment notes    
6. prototype asset folders    
7. a current static prototype folder    
8. archive/export locations  

The current focus is not backend implementation yet.

The current focus is:

- creating a **desktop-first static HTML/CSS/JS prototype**  
- aligning visual direction with **bulldogstats.com**  
- making the UI feel like a **real product**, not a generic admin template  
- making **team-detail.html** the central “working page”  
- preparing a prototype that is strong enough for review and later Laravel implementation planning

## What Has Been Created

### 1. A structured documentation system

The project now has a cleaner numbered document structure, including:

- root-level governance / orientation docs

### 3. A formalized folder structure

The repository has been organized into a predictable structure with numbered folders for:

### 4. A working static prototype directory

A prototype structure now exists at:

`06_Static-Prototype/current/`

Expected prototype files include:

- `index.html`  
- `dashboard.html`  
- `teams.html`  
- `team-detail.html`  
- `create-team.html`  
- `player-identity.html`  
- `guardian-relationships.html`  
- `styles.css`  
- `app.js`

This prototype is intended to remain static and lightweight for the review phase.

---

### 5. A brand-aligned visual direction

The prototype direction has been refined to align more closely with **bulldogstats.com**.

The visual intent is now clearly documented as:

- dark/navy foundation  
- Bulldog green accents/actions  
- bold, confident headings  
- restrained, serious product styling  
- desktop-first composition  
- product UI rather than marketing-site layout  
- no generic admin-template feel  
- no fake mascot graphics or clip-art
